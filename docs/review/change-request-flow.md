# 增量需求同步流程

## 启动规则

- “加入需求池”“记录需求”只登记，不实施。
- 只有用户明确表达“开始处理、实现、同步 CR-xxx”才进入影响分析。
- 影响分析完成前，不根据标题填写 Page、Action 或 State ID。
- 用户最终评审前，不得更新为“已同步”。

## 固定流程

`已登记 → 待启动 → 影响分析 → 规则确认 → 决策记录 → 页面契约 → 可交互原型 → 页面说明 → 一致性检查 → 用户评审 → 已同步`

节点状态只使用：

`未开始、进行中、等待用户、已完成、已跳过、被阻塞`

## 总状态

- 当前节点为“待启动”：未同步。
- 已启动且未完成：同步中。
- 当前节点为“已同步”：已同步。

## 关闭条件

- 必需节点全部完成。
- 可选节点完成或有理由跳过。
- 相关检查通过。
- 存在明确用户确认日期和证据。
