# 需求质量审查总控清单

## 固定顺序

1. 页面文档结构合规审查。
2. 需求口径一致性审查。
3. 决策落地一致性审查。
4. 合并去重。
5. 真实样本和对抗样本验证。
6. 人工确认 P0、P1 和待确认项。
7. 确认后再修复。
8. 修复后重新检查。

## 去重规则

同一基线规则、同一业务根因、同一修正动作，只报告一次。

## 每条问题字段

- 问题编号。
- P0/P1/P2。
- 确认状态。
- 问题性质。
- 主问题类型。
- 辅助标签。
- 文件和章节。
- 最小证据。
- 当前有效基线及有效性说明。
- 问题、影响、建议。
- 回写目标。

## 退出条件

- P0 为 0。
- P1 已解决或明确阻断后续交付。
- P2 已记录。
- 修复有证据且重新检查通过。
