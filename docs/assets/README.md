# GitHub 首页截图说明

README 使用四张示例截图，按“核心工作方式 + 更多适用场景”分层展示。

## 固定文件名

1. `readme-review-center.png`：评审中心首页；
2. `readme-b2b-demo.png`：订单列表打开审核抽屉；
3. `readme-rule-config.png`：PC 端激励规则设置；
4. `readme-mobile-flow.jpg`：移动端预约成功与订单详情。

## 放置位置

将三张图片放入当前目录：

```text
docs/assets/
```

桌面端优先使用 PNG；移动端组合图可以使用 JPG。截图宽度建议至少 `1200px`，不要截入浏览器收藏栏、其他标签页或个人桌面内容。

替换截图后，需要重新检查文件名、尺寸、README 显示效果以及是否包含不应公开的信息。
