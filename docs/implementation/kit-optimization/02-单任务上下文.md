# 第二批：单任务上下文

优先级：P2。实现与合成验收已完成，真实项目收益尚未测量。

## 对你的实际好处

说“继续 CR-001”或“接着 TASK-002”时，AI 可以先生成该任务的上下文包，看到目标、授权引用、包含与排除范围、验收、阻断问题、前置条件和下一步。你不需要维护另一份交接表。

快速评审可以按场景提取，工具不会强行新建正式 CR。

## 前后对比

以前默认读取大台账，再从中找当前任务。现在保留原台账，工具在本地选择当前条目，只向对话返回相关内容。AGENTS 保留稳定底线，导航技能按任务选择材料，取消默认重复读取 README 等入口。

新增 task:context；支持 CR、TASK、评审场景。默认输出 JSON，指定输出文件时同时生成简短 Markdown。文件摘要和生成时间用于恢复前复核，包被改写、直接来源变化或缺失时不能当作当前事实。

默认 20 KiB 软预算。核心范围、授权和验收不静默截断；代码片段超出预算会列入待展开清单。静态相对 import 会跟随读取，无法解析的动态依赖仍需人工定位。

## 边界与验收

材料引用不是已阅读材料全文。代码只提供有限片段，文档仍可能需要按引用继续读取。当前不做台账物理分片，也未迁移真实业务项目。TASK 材料里的历史版本标签不会被自动当作事实确认。

建议产品验收：查看一个任务包，能否不打开整个台账就明确“这次做什么、不做什么、谁批准、如何验收、下一步是什么”。
