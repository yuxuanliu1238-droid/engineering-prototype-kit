# 页面功能说明

页面说明用于向产品、业务、研发和测试解释页面，不独立覆盖业务决策、状态机、页面契约或当前原型。

每个正式页面至少说明：

- 页面目标和所属角色；
- 入口和前后页面；
- 页面结构和可见字段；
- 动作的业务目的、可见状态、前置条件和校验；
- 正常、空、异常和取消恢复状态；
- 数据来源和敏感性；
- 当前已实现、部分实现和计划中能力；
- 待确认接口与外部依赖；
- 验收事实。

后台管理页面和移动端旅程可以使用不同模板，但必须与页面契约保持映射。

## B 端体验检查

后台页面交付前至少检查：

- 列表、详情、抽屉和弹窗遵循宿主系统已有导航方式；
- 核心结果优先展示，相同信息没有无目的重复；
- 常用窗口宽度和缩放比例下，表格、卡片与操作不溢出；
- 下拉、树形选择和临时弹层可明确关闭，取消后能恢复，点击外部可按约定收起。

检查结论必须附页面、场景、截图或自动化结果等证据，不能只填写“已检查”。仅为评审服务的场景切换、恢复数据和过程演示动作，应标为“仅评审”，不进入正式业务需求。
