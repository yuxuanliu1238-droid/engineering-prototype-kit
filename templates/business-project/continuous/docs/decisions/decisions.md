# 正式决策台账

> 只记录会长期影响产品结果或需要防止误恢复的正式结论。普通文案、样式和局部小交互保留在对应 CR。

## 准入条件

满足至少一项才能进入正式决策：

- 改变业务结果；
- 改变角色责任或权限边界；
- 影响核心状态或异常处理；
- 影响多个页面或后续需求；
- 明确禁止恢复某项能力或字段；
- 曾存在争议且需要保留确认依据。

## 决策记录

### DEC-001 决策标题

- 类型：采用 / 禁止 / 已替代。
- 状态：候选 / 已确认 / 已替代。
- 来源：待填写。
- 背景：待填写。
- 结论：待填写。
- 适用范围：待填写。
- 影响：待填写。
- 验收标准：待填写。
- 确认人：待确认。
- 确认日期：待确认。
- 替代关系：无或填写被替代/替代的决策编号。

候选内容不得作为正式业务基线。决策被替代时保留历史，不直接删除。
