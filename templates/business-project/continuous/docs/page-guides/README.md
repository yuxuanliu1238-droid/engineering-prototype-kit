# 页面说明

页面说明是页面契约与当前原型的可读生成视图，不是独立业务事实源。

- 快速验证模式不创建正式页面说明；
- 轻量变更只展示目标页面、变更点和验收结果；
- 标准需求展示页面、动作、状态和可观察验收事实；
- 高风险需求增加数据敏感性、权限、异常、外部集成和恢复方式；
- 页面契约和原型冲突时，页面说明不得静默选择一方；
- 生成视图不得恢复已明确移除或禁止的字段和能力。
- 每个动作说明业务目的、可见状态和前置条件；仅评审动作不得写成正式业务能力；
- B 端页面至少检查导航层级、信息重复、常用宽度、表格或卡片溢出，以及下拉、抽屉和弹窗的关闭与取消恢复；
- 业务口径变化后，页面说明只能在字段、规则、状态、页面、演示数据和验收场景的影响清单更新后重新生成。

本目录由生成器维护。产品经理确认业务结论，不直接同步多份页面文档。
