# {{PROJECT_NAME}}产研交接

本目录只在产品经理明确选择“进入真实研发交接”后创建。未启用产研交接时，业务项目不需要本目录，也不会因缺少研发任务清单而校验失败。

## 日常使用

1. AI 根据已确认需求和原型维护 `development-handoff.json` 草稿；
2. 研发评审后，AI 只整理新增、拆分、合并、删除和归类差异；
3. 产品与研发双确认后，生成 `development-task-list.md` 正式清单；
4. 研发明确选择一个任务时，才在 `task-contexts/` 准备材料上下文，并在 `task-prompts/` 生成对应提示词；
5. 生成提示词不构成实施授权，真正修改代码仍需单独明确授权。

Git、钉钉文档、原型、截图和接口文档都可以作为材料入口。无法自动核对版本时应标记为未核对并由人工确认，不得保存账号、密钥、令牌或生产配置。
