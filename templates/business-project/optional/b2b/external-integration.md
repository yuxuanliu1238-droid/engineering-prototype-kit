# 外部系统与状态同步检查

> 仅在持续迭代且需求触达真实外部系统或跨系统状态时启用。

- 外部系统、责任方和数据方向；
- 请求、回调、轮询或人工导入的触发方式；
- 两侧状态映射和最终事实来源；
- 超时、重复、乱序和部分成功；
- 鉴权、敏感字段和日志脱敏要求；
- 补偿、重试、人工修复和关闭条件。

## 字段与推导链

| 业务字段 | 字段类型 | 责任方 | 来源字段/计算依据 | 获取或计算时点 | 业务用途 | 页面名称 | 缺失处理 |
|---|---|---|---|---|---|---|---|
|  | 业务输入 / 外部返回 / 系统推算 / 仅展示 |  |  |  |  |  |  |

对系统推算字段必须写清输入字段、计算方式和计算时点。外部接口没有返回的字段不得写成接口返回值；业务展示名称不得反向改变原始字段含义。
